隱私權政策

生效日期：2026-10-20。適用於由 Alan 管理、供帳戶擁有人個人使用的 Hermes Gmail Manager。

存取哪些資料及用途

經 Google OAuth 同意後，工具僅使用 gmail.readonly 權限。按照使用者指令讀取郵件及對話編號、寄件者與收件者、主旨、日期、標籤、正文及附件名稱，包括判斷跟進狀態所需的相關已寄回覆。用途限於搜尋、分類、摘要、跟進事項辨識及封存建議。不下載附件、不開啟郵件內連結，也不修改 Gmail。

AI 及資料傳送

選定的郵件內容及相關上下文會傳送至 Hermes 當時設定的 AI 模型服務，以完成使用者要求的分析。摘要、判斷及短引用會由 Hermes 經 Telegram 傳送至獲授權的原對話。Google 處理 OAuth 及 Gmail API 請求；VPS 主機服務、AI 模型服務及 Telegram 會在提供相應服務時處理相關資料，其服務條款、保留與處理設定亦適用。實際模型服務由帳戶擁有人在 Hermes 設定中控制；不應在不了解其資料處理安排下提交敏感郵件。

管理者不出售郵件資料，不將 Google 使用者資料用於廣告、資料經紀或訓練通用 AI／機器學習模型。Google API 資料的使用及轉移須遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保存與刪除

OAuth 憑證存於 VPS 的私密檔案。Gmail 插件不另建長期完整郵件正文庫；完整正文暫存於分析程序記憶體。工作狀態、候選清單、摘要、短引用及送達記錄保存於 VPS，工作七日後不可透過工具存取，並於下次操作或手動清理時刪除，因此閒置期間不保證第七日立即從磁碟移除。

Hermes 對話紀錄、VPS 備份、AI 服務及 Telegram 的資料可能按各自設定另行保留；上述七日期限不涵蓋這些副本。帳戶擁有人可聯絡管理者清理可控制的本機及 VPS 資料，並按各服務提供的方式刪除其他紀錄。

控制與安全

使用者可隨時在 Google 帳戶第三方連線設定撤銷授權，停止後續 Gmail 存取；撤銷不會自動刪除先前摘要或紀錄。工作按 Telegram 使用者及對話隔離；憑證以限制權限的檔案保存。網絡服務及 AI 判斷均無法保證絕對安全或正確。

本網站

本網站不讀取 Gmail、不含分析追蹤程式或登入表單。網站由 GitHub Pages 提供，GitHub 可能按照其隱私權聲明處理訪客 IP 等基本請求資訊。
